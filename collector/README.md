# AI CLI 用量收集器（任何一台 Windows 電腦）

## 它是做什麼的

AI CostScale 的用量有兩個來源，收的方式不一樣：

| 用量 | 怎麼被記錄 | 需要這個收集器嗎 |
|---|---|---|
| **專案透過閘道打的 API**（虛擬金鑰） | 每一筆呼叫都經過閘道，**閘道自己記帳** | **不需要** |
| **你自己在電腦上用 Claude Code、Codex**（訂閱） | 不經過閘道，閘道看不到 | **需要**，就是這一包 |

這一包讀你電腦上 Claude Code 與 Codex 自己留下的 session 紀錄，把 token 數字回報給儀表板，
「總覽」頁的「訂閱省下多少」才算得出來：同樣的 token 如果走官方 API 要付多少，減掉你付的月費。

**不會送出任何對話內容。** 只送 session 編號、模型名稱、token 數字、時間、這台電腦的名稱。

---

## 裝之前要準備的兩個值

都在伺服器的 `/opt/costscale/.env` 裡：

| 值 | `.env` 裡的欄位 | 例子 |
|---|---|---|
| 儀表板網址 | `AUTH_URL` | `https://cost.example.com` |
| 回報 token | `OTEL_INGEST_TOKEN` | 一長串英數字 |

---

## 怎麼裝

1. 把**整個 `collector` 資料夾**複製到那台電腦（放桌面就可以）。
2. 雙擊 **`1-安裝.bat`**。
3. 照畫面貼上儀表板網址與 token。它會先試著回報一次，**網址或 token 不對會直接告訴你，不會裝一個送不出去的東西。**
4. 看最後的「結果」，按 Enter 關閉視窗。

每 30 分鐘在背景回報一次，沒有視窗、不需要系統管理員。

### 要裝很多台：做成雙擊就好的包

在這個資料夾裡建兩個文字檔，之後複製到每台電腦都**不用再輸入**：

- `_url.txt`：內容只有一行，儀表板網址
- `_token.txt`：內容只有一行，回報 token

> 這兩個檔含機密，已列在 `.gitignore`，不會被推上 GitHub。**不要把放了這兩個檔的資料夾傳給不信任的人。**

---

## 它會偵測哪些

看的是「這台有沒有用過」（紀錄檔在不在），不是「有沒有裝程式」。沒用過的會自動略過，不是錯誤。

| CLI | 收得到什麼 | 判斷依據 |
|---|---|---|
| Claude Code | 分模型的完整 token（輸入、輸出、快取讀寫） | `%USERPROFILE%\.claude\projects` 有沒有會話檔 |
| Codex | 分模型的完整 token | `%USERPROFILE%\.codex\sessions` 有沒有 session 檔 |
| Antigravity | **收不到** | 它把對話存成 SQLite，token 數字在沒有欄位名的 protobuf 裡，本機沒有可讀的 token 數 |

之後在這台開始用新的 CLI：**再雙擊一次 `1-安裝.bat`**，會重新偵測、自動接上。重跑是安全的。

---

## 確認它真的在跑

看紀錄檔最後幾行（有裝哪個看哪個）：

```
%LOCALAPPDATA%\costscale-claude-usage.log
%LOCALAPPDATA%\costscale-codex-usage.log
```

正常的樣子：

```
2026-09-07 16:59:26 解析：838 則帶用量的訊息，湊成 1 個 (session, 模型)，解析失敗 0 行。
2026-09-07 16:59:27 OK 第 1 批送出 1 筆，寫入 1。
2026-09-07 16:59:27 迴圈：一輪結束，退出碼 0
```

「解析」「送出」「退出碼 0」三行都要有。只有「一輪結束」而沒有前兩行，代表那一輪什麼都沒做。
儀表板「總覽」的 CLI 用量那一區，也會出現這台電腦的名字。

第一次要把過去的紀錄全掃一遍，一到兩分鐘；之後每一輪只讀有變動的檔，一兩秒。

---

## 移除

雙擊 **`2-移除.bat`**。已經送出去的資料不會被刪，那些在伺服器上。

---

## 出問題的時候

| 看到 | 意思 |
|---|---|
| `這台沒有用過，略過` | 正常，不是錯誤 |
| `token 不對（伺服器回 401）` | 貼錯了，要貼 `.env` 的 `OTEL_INGEST_TOKEN` |
| `網址不對（伺服器回 404）` | 填儀表板網址（`AUTH_URL`），不是閘道網址 |
| `伺服器沒有啟用回報（回 503）` | 伺服器 `.env` 的 `OTEL_INGEST_TOKEN` 是空的，填好後重啟 dashboard |
| 紀錄檔出現 `送出失敗` | 網路不通，或伺服器換過 token——重跑 `1-安裝.bat` 貼新的 |

---

## 技術備註

- 資料以電腦名稱（`COMPUTERNAME`）區分；`session_id` 是 UUID，同一包裝在很多台也不會互相覆蓋。
- 背景執行用「啟動資料夾 ＋ 隱藏視窗的常駐迴圈」，不用 Windows 工作排程器：
  沒有密碼的帳號，非互動的排程工作會回報成功卻根本沒執行。
- 兩個設定存在**使用者環境變數**：`COSTSCALE_CLI_USAGE_URL`、`COSTSCALE_INGEST_TOKEN`。
- 從舊版升級：Claude Code 收集器發現紀錄是舊格式時，會自動把本機紀錄全部重送一次，把新增的「1 小時快取寫入」補上。
